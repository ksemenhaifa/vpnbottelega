# Установка на veliora.clinic

## Что это делает

Все телефоны, почта и кнопки «Записаться» на сайте начинают вести в WhatsApp.
Клиент нажимает — у него открывается чат клиники с **уже написанным сообщением**:

> Здравствуйте! Пишу с вашего сайта — Лазерная эпиляция (Цены).
> Можете рассказать подробнее?
>
> — источник: поиск Яндекс, обращение №482913

Клиенту остаётся нажать «отправить». Владельцу клиники видно прямо в переписке,
**с какой страницы и из какого источника** пришёл человек — сайт перестаёт быть
«просто визиткой» и становится измеримым каналом заявок.

---

## Шаг 1. Указать номер

Откройте `whatsapp-lead.js` и впишите номер WhatsApp клиники в международном
формате, только цифры:

```js
phone: '79991234567',
```

Форматы `8 (999) 123-45-67` и `+7 999 123-45-67` тоже понимаются — скрипт
приведёт их сам. Если оставить поле пустым, номер возьмётся из первой ссылки
`tel:` или `wa.me` на странице.

---

## Шаг 2. Подключить скрипт

Ниже — по одному способу на каждую платформу. Выберите свой.

### Статический сайт (HTML)

Положите `whatsapp-lead.js` в корень сайта и добавьте перед `</body>`
на каждой странице:

```html
<script>
  window.WA_LEAD = {
    phone: '79991234567',
    messagePreset: 'detailed'
  };
</script>
<script src="/whatsapp-lead.js" defer></script>
```

### Tilda

1. Настройки сайта → **Ещё** → **HTML-код для вставки внутрь HEAD**.
2. Вставьте (файл нужно предварительно загрузить в Файловый менеджер Tilda
   и подставить его адрес):

```html
<script>
  window.WA_LEAD = {
    phone: '79991234567',
    messagePreset: 'detailed',
    extraSelectors: '.t-btn, .t-submit, .t396__elem a'
  };
</script>
<script src="https://static.tildacdn.com/.../whatsapp-lead.js" defer></script>
```

3. **Опубликуйте все страницы** — Tilda применяет код только после публикации.

Если проще не грузить файл: вставьте содержимое `whatsapp-lead.js` прямо между
`<script>` и `</script>` в блок **T123 (HTML-код)** в футере.

### WordPress

Плагин **WPCode** / **Code Snippets** → новый сниппет типа «Footer», либо
в `functions.php` активной дочерней темы:

```php
add_action('wp_footer', function () { ?>
  <script>
    window.WA_LEAD = { phone: '79991234567', messagePreset: 'detailed' };
  </script>
  <script src="<?php echo get_stylesheet_directory_uri(); ?>/whatsapp-lead.js" defer></script>
<?php });
```

Файл `whatsapp-lead.js` положите в папку темы.

### Next.js / React / Vue

Положите `whatsapp-lead.js` в `public/` и подключите в корневом layout:

```jsx
import Script from 'next/script';

<Script id="wa-config" strategy="beforeInteractive">
  {`window.WA_LEAD = { phone: '79991234567', messagePreset: 'detailed' };`}
</Script>
<Script src="/whatsapp-lead.js" strategy="afterInteractive" />
```

При клиентской навигации скрипт сам подхватит новые элементы (`watchDom: true`).
Если контент рендерится с задержкой — вызовите `window.WhatsAppLead.refresh()`.

## Шаг 3. Проверить

Откройте `demo.html` из этого репозитория — там видно, как работают все режимы.

На боевом сайте:

1. Наведите курсор на телефон — в статус-баре браузера должен быть `wa.me/...`.
2. Нажмите — открывается WhatsApp с готовым текстом.
3. Откройте сайт с меткой `?utm_source=test` — в сообщении появится источник.
4. Проверьте на телефоне: должен открыться установленный WhatsApp, а не сайт.

## Текст сообщения

Готовые варианты — параметр `messagePreset`:

| Пресет | Текст |
|---|---|
| `neutral` *(по умолчанию)* | Здравствуйте! Пишу с вашего сайта — {{service}}. Можете рассказать подробнее? |
| `found` | Здравствуйте! Нашёл вас на вашем сайте — {{service}}. Можете рассказать подробнее? |
| `short` | Здравствуйте! Интересует {{service}}. Расскажите подробнее? |
| `detailed` | То же + страница, источник трафика и номер обращения |

По умолчанию стоит `neutral`, а не `found`: «нашёл» — мужская форма, а сообщение
отправляет клиент от своего лица. В клинике эстетической медицины большинство
клиентов — женщины, и от их имени уйдёт текст в мужском роде. `neutral`
читается так же, но подходит всем. Если нужен именно ваш вариант — поставьте
`messagePreset: 'found'`.

Свой текст задаётся напрямую:

```js
message: 'Здравствуйте! Интересует {{service}}. Подскажите цену и свободное время?'
```

Плейсхолдеры: `{{service}}` — услуга, `{{page}}` — страница, `{{title}}` —
title страницы, `{{url}}` — адрес, `{{source}}` — источник перехода,
`{{id}}` — номер обращения. Незаполненные плейсхолдеры и лишние пробелы
вычищаются автоматически.

## Как скрипт определяет услугу

По убыванию приоритета:

1. Атрибут `data-wa-service` на элементе или любом его родителе:
   ```html
   <section data-wa-service="Лазерная эпиляция"> ... </section>
   ```
2. Ближайший заголовок секции (`h1`/`h2`/`h3`).
3. Собственный текст кнопки.
4. `h1` страницы или `title`.

Первый вариант точнее всех — разметьте им хотя бы главные услуги.

## Тонкая настройка

```js
window.WA_LEAD = {
  phone: '79991234567',

  convertTel: true,              // ссылки tel:
  convertMailto: true,           // ссылки mailto:
  convertCtaByText: true,        // кнопки «Записаться», «Оставить заявку» и т.п.
  extraSelectors: '.my-button',  // свои селекторы кнопок

  forms: false,                  // 'replace' — вместо отправки формы открыть WhatsApp
                                 // 'after'   — отправить форму И открыть WhatsApp
  floatingButton: true,          // плавающая кнопка в углу
  floatingButtonPosition: 'right',
  yandexCounterId: null,         // номер счётчика Метрики (обычно определяется сам)
  debug: true                    // логи в консоль при отладке
};
```

**Исключения.** Чтобы скрипт не трогал элемент или целый блок:

```html
<a href="tel:+79991234567" data-wa-ignore>Только позвонить</a>
```

**Ручное открытие чата** из своего кода:

```js
WhatsAppLead.open('Консультация хирурга');   // открыть чат
WhatsAppLead.link('Ботокс');                 // получить готовую ссылку
WhatsAppLead.refresh();                      // перепривязать после подгрузки контента
```

## Аналитика: чем отчитываться перед заказчиком

При каждом клике скрипт отправляет событие `whatsapp_lead` в Яндекс.Метрику,
Google Analytics 4, `dataLayer` и как DOM-событие `wa-lead:click`.

Настройка цели в Метрике: **Настройка → Цели → Добавить цель → JavaScript-событие**,
идентификатор — `whatsapp_lead`.

После этого в отчётах видно: сколько человек написали в WhatsApp, с каких
страниц и из каких источников. Это и есть ответ на вопрос «а что мне дал сайт».

## Что важно знать

- **Номер должен быть зарегистрирован в WhatsApp**, иначе ссылка откроет ошибку.
  Для клиники лучше **WhatsApp Business** — там автоответ в нерабочее время,
  быстрые ответы и каталог услуг.
- **Первое сообщение отправляет клиент**, не клиника. Это соответствует правилам
  WhatsApp: рассылки без согласия запрещены, а входящее обращение открывает
  24-часовое окно свободной переписки.
- **Не убирайте телефон со страницы контактов совсем.** Часть клиентов
  (особенно старшего возраста) хочет именно позвонить. Оставьте один
  честный `tel:`-номер с атрибутом `data-wa-ignore`.
- Скрипт не собирает и никуда не отправляет персональные данные. В `localStorage`
  хранится только источник перехода и номер обращения, на 30 дней.
