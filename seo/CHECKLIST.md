# SEO-план для veliora.clinic

Порядок здесь не случайный: сверху то, что даёт заявки в первые недели,
снизу — то, что работает на дистанции 3–6 месяцев. Делайте сверху вниз.

> **Важно про медицинскую тематику.** Сайты клиник Яндекс и Google относят к
> YMYL («деньги или жизнь») и проверяют строже обычных. Без лицензии, реальных
> врачей и юрлица на сайте выйти в топ практически невозможно — сколько бы
> ключевых слов вы ни добавили. Пункты 3 и 4 здесь важнее любой техники.

---

## 0. Сначала — замер, иначе нечего показывать заказчику

Без этого невозможно доказать, что сайт приносит клиентов.

- [ ] **Яндекс.Метрика** установлена, включён вебвизор.
- [ ] **Цель «Обращение в WhatsApp»** — тип «JavaScript-событие», идентификатор
      `whatsapp_lead`. Скрипт `whatsapp-lead.js` отправляет это событие сам.
- [ ] **Google Analytics 4** (если нужен) — событие `whatsapp_lead` приходит автоматически.
- [ ] **Яндекс.Вебмастер** — сайт добавлен и права подтверждены.
- [ ] **Google Search Console** — то же самое.
- [ ] Сделан **скриншот нулевых показателей на старте**. Через месяц рядом
      кладётся второй — это и есть отчёт заказчику.

## 1. Техника: чтобы сайт вообще индексировался

Типовые причины, по которым сайт «есть, а в поиске его нет»:

- [ ] В коде **нет** `<meta name="robots" content="noindex">`. Проверьте на всех
      страницах — часто остаётся с этапа разработки. Это причина №1.
- [ ] В `robots.txt` **нет** `Disallow: /` (тоже наследие разработки).
- [ ] Сайт открывается **только по одному адресу**. Остальные три отдают 301:
      `http://` → `https://`, `www.` → без `www` (или наоборот — главное единообразно).
- [ ] У каждой страницы есть уникальный `<link rel="canonical">`.
- [ ] `sitemap.xml` лежит в корне и загружен в обе панели вебмастеров.
- [ ] `robots.txt` лежит в корне и содержит строку `Sitemap:`.
- [ ] SSL-сертификат валиден и не истекает в ближайший месяц.
- [ ] Несуществующие адреса отдают **404**, а не 200 с пустой страницей.
- [ ] Проверено в Search Console → «Проверка URL»: страница проиндексирована,
      Google видит её так же, как пользователь.

Файлы `seo/robots.txt` и `seo/sitemap.xml` в этом репозитории — готовые шаблоны,
поправьте адреса под реальную структуру и положите в корень сайта.

---

## 2. Заголовки и мета-теги: по ним кликают в выдаче

- [ ] На каждой странице **ровно один `<h1>`**, и в нём есть услуга и город.
- [ ] Заголовки идут по иерархии: h1 → h2 → h3, без пропусков уровней.
- [ ] `<title>` **уникален** на каждой странице, 50–60 символов,
      по формуле: `Услуга + Город + Veliora`.
- [ ] `<description>` уникален, 140–160 символов, содержит призыв к действию.
- [ ] У всех изображений заполнен `alt` — описание того, что на фото,
      а не «image1.jpg».
- [ ] Картинки в **WebP**, каждая до ~200 КБ, с явными `width` и `height`
      (иначе страница «прыгает» при загрузке — это портит Core Web Vitals).

Шаблон всех тегов: `seo/head-snippet.html`.

---

## 3. Доверие (E-E-A-T) — для клиники это половина успеха

Поисковики и живые люди проверяют одно и то же. Пока этого нет, топа не будет.

- [ ] **Номер медицинской лицензии** и скан/фото — в подвале и на отдельной странице.
- [ ] **Юрлицо, ИНН, ОГРН, юридический адрес** — в подвале.
- [ ] Страница **«Врачи»**: на каждого — фото, ФИО, специализация, стаж,
      дипломы и сертификаты, ссылка с карточки услуги на врача.
- [ ] Под каждой медицинской процедурой — **противопоказания** и
      «имеются противопоказания, необходима консультация специалиста».
- [ ] **Политика конфиденциальности** и **согласие на обработку персональных
      данных** — обязательны по 152-ФЗ, если на сайте есть формы.
- [ ] **Реальные отзывы** с указанием источника (Яндекс.Карты, 2ГИС, Продокторов).
- [ ] **Цены** на сайте. Страница без цен теряет и позиции, и заявки.

> Не размечайте `aggregateRating` и не публикуйте выдуманные отзывы. За фейковые
> рейтинги в микроразметке прилетает ручная санкция, а снять её долго.

---

## 4. Локальное SEO — самый быстрый источник заявок

Для клиники карты дают заявки **раньше**, чем органический поиск. Часто — в первую же неделю.

- [ ] **Яндекс.Бизнес**: карточка создана, подтверждена, заполнена целиком —
      часы работы, телефон, сайт, 15+ фото, полный список услуг.
- [ ] **2ГИС**: то же самое.
- [ ] **Google Business Profile**: то же самое (если регион актуален).
- [ ] **Продокторов / НаПоправку / Zoon** — профили клиники и каждого врача.
- [ ] **NAP-единообразие**: название, адрес и телефон написаны **абсолютно
      одинаково** везде — на сайте и во всех справочниках. Разнобой («ул.» vs
      «улица», разные форматы телефона) размывает сигнал.
- [ ] Ссылка на сайт стоит во всех карточках.
- [ ] Настроен сбор отзывов: после визита — QR-код или сообщение в WhatsApp
      со ссылкой на карточку в Яндекс.Картах.

---

## 5. Структура: страница на каждую услугу

Главная ошибка сайтов клиник — **одностраничник или общая страница «Услуги»**.
Запрос «`лазерная эпиляция <город>`» ведёт на страницу, посвящённую именно
лазерной эпиляции. Общая страница по нему не ранжируется почти никогда.

- [ ] Отдельный URL на каждую услугу: `/uslugi/lazernaya-epilyaciya/`.
- [ ] На странице услуги: описание, показания, противопоказания, этапы,
      длительность, **цена**, врач, 3–5 фото, FAQ, кнопка WhatsApp.
- [ ] ЧПУ-адреса латиницей, без `?id=123`.
- [ ] Хлебные крошки с разметкой `BreadcrumbList`.
- [ ] Перелинковка: с услуги — на врача и на цены, с блога — на услугу.

---

## 6. Семантика: по каким запросам вас ищут

- [ ] Собрано ядро через Яндекс.Вордстат + подсказки поиска + «Ключевые слова»
      в Метрике (там видны запросы, по которым уже приходят).
- [ ] Ядро разбито по страницам: **один интент — одна страница**.
- [ ] Обязательно включены геозапросы: `<услуга> <город>`,
      `<услуга> рядом со мной`, `<услуга> недорого`, `<услуга> цена`.
- [ ] Проверены конкуренты из топ-10: какие у них страницы и объём текста.
- [ ] Текст написан для людей. Переспам ключами в медтематике даёт
      обратный эффект — фильтр за переоптимизацию.

---

## 7. Скорость (Core Web Vitals — прямой фактор ранжирования)

- [ ] PageSpeed Insights: **мобильная** версия ≥ 80. Мобильная важнее десктопной —
      индексация давно mobile-first.
- [ ] LCP < 2.5 с, CLS < 0.1, INP < 200 мс.
- [ ] Все картинки — WebP, с `loading="lazy"` (кроме первого экрана —
      там `fetchpriority="high"`).
- [ ] Шрифты: `font-display: swap`, лишние начертания убраны.
- [ ] Сторонние скрипты (чаты, виджеты, пиксели) — с `defer`/`async`.
      Каждый лишний виджет замедляет сайт; оставьте только нужные.

---

## 8. Контент, который приводит заявки

- [ ] Блог/статьи по вопросам клиентов: «как подготовиться к…»,
      «сколько держится результат…», «больно ли…».
- [ ] Каждая статья заканчивается ссылкой на услугу и кнопкой WhatsApp.
- [ ] Раздел FAQ с разметкой `FAQPage` (`seo/schema-faq.json`).
- [ ] Фото «до/после» — с согласия пациентов, с `alt` и подписями.

---

## Что проверить через месяц

Открывайте эти четыре цифры и показывайте заказчику:

1. **Яндекс.Метрика → Цели → «Обращение в WhatsApp»** — сколько обращений с сайта.
2. **Метрика → Источники → Поисковые системы** — сколько людей пришло из поиска.
3. **Вебмастер → Индексирование** — сколько страниц в индексе.
4. **Вебмастер → Поисковые запросы** — по каким запросам вас уже находят.

Каждое сообщение в WhatsApp приходит с указанием страницы и источника перехода
(«поиск Яндекс», «Instagram», конкретная utm-метка). Владельцу не нужно верить
на слово — он видит это прямо в переписке.
