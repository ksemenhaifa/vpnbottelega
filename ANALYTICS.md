## Что осталось сделать руками

### 1. Заменить счётчики на сайтах

Сейчас `veliora.clinic`, `3dlab.co.il` и `yallapro.co.il` шлют данные в
`G-72QJ6FFJ6N` — счётчик сайта web1. Замените в коде каждого сайта на его
собственный из таблицы выше:

```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-26EE1W3M11"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-26EE1W3M11');
</script>
```

На `aqualit63.ru` и `газтехника-самара.рф` GA4 не было вообще — поставьте с нуля.

> Старую историю это не переносит: новый ресурс начинает считать с нуля.
> Общий `G-72QJ6FFJ6N` не удаляйте, в нём лежат данные за прошлые месяцы.

### 2. Поставить `contact-tracker.js`

На каждый сайт, перед `</body>`, **после** кода счётчика:

```html
<script>window.CT = { site: 'veliora.clinic' };</script>
<script src="/contact-tracker.js" defer></script>
```

На `3dlab.co.il` и `yallapro.co.il` своё событие `whatsapp_click` уже есть —
добавьте `skipWhatsApp: true`, иначе обращения задвоятся.

### 3. Привязать Search Console — это и есть «по каким запросам»

**GA4 сам поисковых запросов не знает.** Их даёт только Search Console.
Через API эта привязка не делается, только вручную, для каждого ресурса:

Администратор → **Связи с сервисами** → **Связи с Search Console** →
**Связать** → выбрать ресурс Search Console → выбрать поток данных → Отправить.

После этого в GA4 появится отчёт **Отчёты → Как привлекаются пользователи →
Запросы Google Поиска**: запрос, показы, клики, CTR и позиция.

> Ограничение, которое важно понимать: связать запрос с конкретным обращением
> в WhatsApp нельзя. Google не отдаёт запрос на уровне пользователя — только
> сводно по страницам. Для связки «запрос → заявка» нужна реклама с UTM-метками,
> их `contact-tracker.js` уже пишет в параметр `traffic_source`.

### 4. Привязать Google Ads — для рекламных кампаний

Администратор → **Связи с сервисами** → **Связи с Google Рекламой** → **Связать**.

Это даёт:
- кампании, группы объявлений и ключевые слова в отчётах GA4
- импорт ключевых событий (`whatsapp_click` и прочих) в Google Ads как конверсий
- ремаркетинг на тех, кто был на сайте, но не написал

Без этой связки оптимизировать рекламу по обращениям не получится: Google Ads
не будет знать, какие клики приводили к заявкам.

### 5. Отключить внутренний трафик

Чтобы ваши собственные заходы не портили статистику:

Администратор → **Потоки данных** → выбрать поток → **Настроить параметры тега** →
**Определить внутренний трафик** → добавить свой IP.

## Отчёт «что дал сайт»

GA4 → Исследования → Пустое исследование:

- **Параметры:** `site`, `page_path`, `section`, `traffic_source`
- **Показатели:** `Количество событий`, `Активные пользователи`
- **Фильтр:** `Название события` — один из `whatsapp_click`, `telegram_click`, `phone_click`
- **Строки:** `page_path` → `section`

Даст таблицу «страница → блок → сколько обращений» с разбивкой по источнику.

Специальные параметры появляются в отчётах через 24–48 часов после первых
данных. В отчёте «В реальном времени» видны сразу.
