# veliora.clinic — SEO и заявки в WhatsApp

Набор для сайта клиники Veliora: усиление SEO + перевод всех контактов сайта
в WhatsApp с готовым первым сообщением.

**Задача:** владелец клиники должен видеть, что заплатил за разработку не зря —
клиенты приходят с сайта, и это видно в переписке и в отчётах Метрики.

## Что внутри

| Файл | Назначение |
|---|---|
| `whatsapp-lead.js` | Скрипт: все телефоны, почта и кнопки «Записаться» ведут в WhatsApp с готовым текстом |
| `demo.html` | Демо-страница — открыть в браузере и посмотреть, как это работает |
| `INSTALL.md` | Установка на Tilda, WordPress, статический сайт, Next.js |
| `seo/CHECKLIST.md` | Пошаговый SEO-план по приоритету: от быстрых заявок к долгой органике |
| `seo/head-snippet.html` | Готовые мета-теги для `<head>`: title, description, canonical, Open Graph |
| `seo/schema-medicalclinic.json` | Микроразметка клиники (расширенный сниппет в выдаче) |
| `seo/schema-faq.json` | Микроразметка FAQ |
| `seo/robots.txt` | robots.txt с `Clean-param` для Яндекса |
| `seo/sitemap.xml` | Шаблон карты сайта |

## Быстрый старт

1. Впишите номер WhatsApp в `whatsapp-lead.js` (поле `phone`).
2. Подключите скрипт на сайт — см. `INSTALL.md`.
3. Пройдите `seo/CHECKLIST.md` сверху вниз.

Проверить локально:

```sh
npx http-server -p 8080 .   # затем открыть http://localhost:8080/demo.html
```

## Как выглядит результат

Клиент нажимает любой контакт на сайте — открывается WhatsApp клиники
с уже написанным сообщением:

> Здравствуйте! Пишу с вашего сайта — Лазерная эпиляция (Цены).
> Можете рассказать подробнее?
>
> — источник: поиск Яндекс, обращение №482913

Владельцу сразу видно, с какой страницы и из какого канала пришёл человек.

## Ограничения

Файлы с плейсхолдерами (`{{...}}`, `ЗАМЕНИТЕ`) требуют реальных данных клиники:
адрес, телефон, номер лицензии, услуги, координаты. Собранная разметка без этих
данных на сайт не выкладывается — поисковики считают незаполненную разметку
ошибкой.
